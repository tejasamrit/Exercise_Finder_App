# 🏋️‍♂️💛 Exercise Finder App

🔗 **Live Demo**: [Exercise Finder Application](https://exercisefinderapp.netlify.app/)

---

## 📖 About the Project

Exercise Finder is a responsive and interactive web application designed to help users discover the right exercises based on the part of the body that hurts or needs training.

With the help of the **ExerciseDB API**, this app offers an extensive collection of exercises, including **GIF demonstrations**, **target muscle groups**, **equipment used**, and more. Users can filter workouts by body part, choose home-based exercises, and even save their favorite ones for quick access.

Whether you're a fitness beginner or a workout enthusiast, this app makes it easy to find the perfect exercises tailored to your needs!

---

## 🛠️ Tech Stack

- **HTML5** – For structuring the web content
- **CSS3** – For beautiful styling and responsive layout
- **JavaScript (Vanilla)** – For API integration and interactivity
- **ExerciseDB API** – To fetch real-time exercise data and media
- **Netlify** – For deployment and live hosting

---

## 🚀 Key Features

- 🔍 **Search Exercises**: Enter the hurting body part and find relevant exercises.
- 📂 **Body Part Filter**: Quickly filter exercises using a scrollable menu.
- 🏠 **Home Workouts**: Filter exercises that require no equipment (body weight only).
- ❤️ **Favorites Management**: Save and delete favorite exercises using localStorage.
- 🖼️ **Exercise Cards**: Each card displays exercise name, animated demo GIF, target muscle, and equipment.
- 🎨 **Animated UI**: Includes smooth transitions, a black & yellow theme, and responsive card layouts.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile screens.
- 📌 **Sticky Footer**: A simple footer with “Made with love by TejasAmrit” always stays at the bottom.

## 📁 How to Run Locally

1. **Clone the repository**:
```bash
git clone https://github.com/your-username/ExerciseFinderApp.git
```

2. **Navigate to the project directory**:
```bash
cd ExerciseFinderApp
```

3. **Open `index.html` in your browser**. No additional server setup is required.
